Cloud Poodll Assignment Submission
========================================

Cloud Poodll Assignment Submission adds audio, video and whiteboard recording as a native Moodle
Assignment submission type. Students record directly in the browser; recordings are processed and
stored in the Cloud Poodll cloud, so your Moodle server and course backups stay small. Because
it's a real assignment submission plugin, it works with Moodle's normal grading, feedback and
portfolio export.

Cloud Poodll requires a Cloud Poodll API username and secret from https://poodll.com
See here: https://support.poodll.com/support/solutions/articles/19000083076-cloud-poodll-api-secret

See README.md in this folder for the full documentation: features, installation, site settings,
recorders/skins, and transcription/transcoding options.
